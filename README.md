# 第一代极米 Z6X 手动校正预设

一款面向**第一代极米 Z6X（硬件型号必须为 XH25L）**的 Android TV 小工具，用来保存和快速应用多组手动投影校正数据。

> [!WARNING]
> 本项目仅在硬件型号 `XH25L` 上开发和验证。Z6X 的其他代次、后续版本、海外版本及其他极米机型，即使外观或名称相近，也不保证兼容。请先在“系统信息”中确认硬件型号；不是 `XH25L` 请勿安装或使用。

## 为什么需要它

第一代 Z6X 没有新款投影仪上更完善的自动画面校正能力。投影仪在客厅、卧室、侧投位置或不同幕布之间移动时，通常需要重新进行手动校正，重复调整比较麻烦。

本应用采用“**手动校正 + 预设**”的方式：

1. 先使用投影仪原生界面完成一次手动校正；
2. 在应用中把当前校正结果保存为预设；
3. 更换投影位置后，直接应用对应预设。

它不会把旧设备变成自动校正设备，而是让已经调好的多个投影环境能够更方便地来回切换。

## 功能

- 六个手动校正预设，采用适合遥控器的 3 × 2 电视布局；
- 每个预设都可以自定义名称，例如“客厅墙面”“卧室侧投”；
- 保存当前校正数据；
- 一键应用已保存的预设；
- 保存时间、空槽位和旧数据状态提示；
- 保存前确认与应用前确认可分别开启或关闭；
- 完整的遥控器方向键焦点导航；
- 不需要 Root，不修改或刷写系统固件。

## 使用方法

### 保存投影环境

1. 在极米系统设置中完成手动投影校正；
2. 打开本应用；
3. 选择一个槽位，点击“保存当前”；
4. 确认后，该槽位会记录当前校正数据。

如果槽位已经有数据，再次保存会覆盖原数据。

### 应用投影环境

1. 打开本应用；
2. 找到目标预设；
3. 点击“应用预设”；
4. 确认后，应用会提交校正数据并进行硬件回读校验。

### 自定义名称和确认设置

主界面右上角进入“设置”，可以：

- 修改六个预设的名称；
- 分别控制“保存前确认”和“应用前确认”；
- 恢复默认名称和确认设置。

“恢复默认设置”不会删除已经保存的校正数据。

## 工作方式

应用连接第一代 Z6X 系统中的极米显示服务，读取手动校正结果并保存在应用自己的本地偏好数据中。应用预设时，它会调用原系统手动校正界面使用的坐标接口，然后重新读取硬件状态进行一致性检查。

项目不会刷写 BIN、修改系统分区或替换系统应用。即便如此，它仍然使用了 `XH25L` 固件中的私有系统接口，因此必须严格限制在已验证型号上使用。

## 从源码构建

### 环境要求

- JDK，可通过 `JAVA_HOME` 指定；
- Android SDK；
- Android SDK Platform，默认 `android-36.1`；
- Android Build Tools，默认 `36.0.0`；
- 从你自己拥有的 `XH25L` 设备或合法取得的对应固件中提取的私有运行文件。

由于版权原因，仓库**不包含也不分发**极米固件、原厂 APK、DEX 或原生 SO 库。请阅读 [`local-vendor/README.md`](local-vendor/README.md)，并在 `local-vendor/` 中准备：

```text
local-vendor/
├── libdisplaymanager_jni.xgimi.so
├── libgmpfdisplaymanager_hidl.xgimi.so
└── setting_classes.dex
```

设置环境变量并构建：

```bash
export ANDROID_SDK_ROOT=/path/to/Android/sdk
export JAVA_HOME=/path/to/jdk
./scripts/build_apk.sh
```

如 SDK 版本不同，可以覆盖：

```bash
export ANDROID_PLATFORM=android-36.1
export ANDROID_BUILD_TOOLS_VERSION=36.0.0
```

构建结果：

```text
outputs/xh25l-keystone-presets-debug.apk
outputs/xh25l-keystone-presets-debug.apk1
```

`.apk1` 是为部分会隐藏普通 `.apk` 文件的投影仪文件管理器准备的同内容副本。

## 安装

通过 ADB 安装自行构建的 APK：

```bash
adb install -r outputs/xh25l-keystone-presets-debug.apk
```

也可以把 `.apk1` 文件放到 U 盘根目录，在投影仪文件管理器中选择系统安装器打开。

## 只读设备检查

连接并授权 ADB 后，可以先运行：

```bash
./scripts/probe_xh25l.sh 192.168.1.50:5555
```

该脚本只读取设备标识、校正属性和相关服务列表，不会写入设置、推送文件、重启或执行系统更新。

## 模拟器界面测试

`tools/emulator/mock-xgimi-service/` 提供一个仅用于 Android TV 模拟器的极米服务测试桩。它用于检查 1280 × 720 布局、设置页、输入框、确认窗口和遥控器焦点，不具备真实投影校正能力，也不会被打包进正式 APK。
